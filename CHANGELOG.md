# Changelog

## Unreleased

### Скрипты
- Лист персонажа (изображение): убран фон и рамка у названия персонажа (имя, раса, класс — текст прямо на бумаге); убрана внешняя рамка листа; точки-лидеры между названием и значением сделаны приглушённее; добавлены черточки под заголовками секций и под Опыт, Бонус умения, Монеты для отделения; черточки ~70% ширины столбца по центру под заголовками секций; заголовки по центру столбцов; убраны черточки под Опыт, Бонус умения, Монеты; увеличены отступы перед подзаголовками (Испытания, Заклинания).
- Экипировка: у предметов добавлены стоимость (в любых монетах: ПМ, ЗМ, ЭМ, СМ, ММ) и вес (фунты/унции в форматах «5 фунтов», «1 фунт», «2 унции», «5 унц» и т.п.). В редакции 2024 сокращения монет выводятся в верхнем регистре (ЗМ, ПМ и т.д.). Добавление предметов: можно вводить несколько через запятую в одном сообщении, с указанием количества, веса и стоимости (пример: «5 Кинжал, рубин 5 фунтов (50 зм), коробка 14 пм 2 унц 5»). То же работает по команде «сн …» / «экипировка …» (добавить без входа в меню). Удаление по списку: команды «сн удал …», «снаряжение удалить …» (и варианты экип/снар) — удаляются перечисленные предметы; совпадение по названию и стоимости (вес не проверяется), при несовпадении стоимости предмет не удаляется. Без числа в строке удаляется один предмет. Если запрошено больше, чем есть (например, сн удал зелье лечение 100 при 14 зельях), выводится «нет столько (есть N)». Команды «сн очистить …», «сн очисть …», «сн очист …» (и снаряжение/экип/снар) — удаляют все предметы с указанным названием (любая стоимость, весь стак); через запятую можно указать несколько названий.
- Ввод характеристик (создание и редактирование): числа можно вводить через пробел или через запятую (например: 15, 14, 13, 12, 10, 8).
- Создание персонажа: добавлен выбор метода характеристик — Стандартный набор (15, 14, 13, 12, 10, 8), Случайный набор (4d6 drop lowest, затем распределение по характеристикам), Приобретение за очки (27 очков) и ввод вручную.
- Редакция 2024: при выборе расы используется термин «вид», при выборе подрасы — «подвид»; в карточке персонажа для персонажей 2024 отображается «Вид» вместо «Раса»; выбор подвида проверяется по списку подвидов 2024 (только эльф и гном). При создании персонажа сохраняется редакция для отображения.
- Снаряжение переименовано в «Экипировка»: кнопки в меню персонажа, заголовок раздела и команды (экипировка, экип); старые команды снар/сн по-прежнему работают.
- Добавлена команда/кнопка «Редакция» (2014/2024) в главном меню и сохранение выбора пользователя.
- Команды испытаний с помехой/преимуществом теперь корректно обрабатывают формат `пре исп <характеристика>` / `пом исп <характеристика>`; при неверном формате выводится «Команда не распознана» без fallback в другой бросок.
- Команды `исп <характеристика>` принимают сокращения (`лвк`, `мдр`) и полные формы (`ловкость`, `мудрость`).
- Ячейки заклинаний: новый формат команд — `-яч 1` / `-яч1` (потратить 1 ячейку 1 круга), `+яч 1 2` / `+яч1 2` (восстановить 2 ячейки 1 круга); только `яч` — показать текущие ячейки.
- Для класса колдун: команды `+яч`, `-яч` (без числа) и `+яч 2`, `-яч 2` работают без указания круга; круг и максимум ячеек берутся из таблицы по уровню (PHB 5e).
